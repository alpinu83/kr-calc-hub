## 5. 왜 허상이 생기는가 (구조 원인)
1. **완료 상태와 검수 결과가 따로 논다.** 검수가 "수정 필요"라고 해도 작업은 `completed`로 남습니다(B구간 자체 작업 10건, 외부 결과까지 합치면 14건). 대시보드의 "완료"만 보면 진척이 있는 것처럼 보입니다.
2. **팀원에게 실행 수단이 없다.** 무료 API 팀원은 저장소에 커밋할 수 없어 결과가 "수정안"에서 멈춥니다. 그런데도 "PR을 생성하겠습니다", "배포 완료"처럼 써서 실행된 것처럼 보입니다.
3. **검수기 기준이 틀렸다.** 있는 파일을 없다고 판단하는 기준이 브리핑에 고정돼 있어, 맞는 결과를 반려하고 틀린 결과(외주 0건, GA4 봇)는 통과시킵니다.
4. **이미 있는 것을 다시 성과로 센다.** 11/22~24 사람 작업을 허브 성과로 보고합니다.
